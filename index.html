Emby, right on your Enigma2 box

E2EmbyClient is a native Emby client plugin for Enigma2 set-top boxes. Browse your libraries, play movies, series and live content, and control playback with the box's own playback engine — no transcoding gateway, no second app.

Get started View source

Everything you'd expect from a native client

Built specifically for Enigma2 skins and playback engines — GStreamer, HiPlayer or Exteplayer3.

Library browsing

Grid-based library screens for movies, series, box sets and episodes, with an alphabet/character jump bar for fast navigation.

Rich detail views

Dedicated info screens for movies, series, seasons and episodes — cast, plot, ratings, genres and media info.

Full playback control

Resume, play from start, and play trailers. Multiple video/audio version selection, with seek handling tuned per playback engine.

Audio & subtitles

Switch audio and subtitle tracks on the fly, including non-UTF-8 subtitle encodings — Cyrillic, Japanese, Chinese, Arabic and more.

Skip Intro & Up Next

A Skip Intro button for content with intro markers, and an Up Next screen with an autoplay countdown before the next episode.

Item actions

Mark watched/unwatched, favorite/unfavorite, or jump straight to a parent series from any detail screen.

Theme music & notifications

Optional theme music while browsing a movie or series detail screen, plus in-app notifications for connection and playback status.

Multiple servers

Configure and switch between several Emby servers or users, each with its own credentials.

Thumbnail caching

Thumbnail cache to a temporary or persistent (HDD/USB) location, with automatic cleanup.

Requirements

FHD skin

An Enigma2 image running an FHD (1920×1080) skin — the plugin refuses to start on lower resolutions.

Emby Server

An Emby Server instance reachable from the box, plus a valid user account.

Python packages

pillow and requests — installed automatically as dependencies of the .ipk package.

Optional: ServiceApp

Install ServiceApp if you want to use Exteplayer3 as the playback engine.
