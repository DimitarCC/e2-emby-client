FAQ & Troubleshooting

Common questions, plus fixes for the setup, connection and playback issues that come up most often.

General

Is this an official Emby app?

No. E2EmbyClient is an independent, open-source client built specifically for Enigma2 set-top boxes. It is not affiliated with or endorsed by Emby LLC.

Which Enigma2 images does it work on?

Any Enigma2-based image, as long as the active skin runs at FHD (1920×1080) resolution and the box has enough performance for the configured playback engine (GStreamer, HiPlayer, or Exteplayer3 via ServiceApp).

Does it support live TV from Emby?

The plugin plays content exposed by your Emby libraries (movies, series, episodes, and their trailers) through the box's own playback engine. If Stop playing service on home load is enabled, your box's own live TV playback is paused while you browse and automatically restored when you exit.

Setup & connection issues

The plugin refuses to start / shows an error about resolution

E2EmbyClient requires an FHD (1920×1080) skin and checks this on launch. Switch to an FHD skin and reopen the plugin.

"Emby Player" only opens the Setup screen

This is expected the first time you run the plugin, before any server connection is configured. Add a connection as described in Setup & First Run, then exit Setup to reach the home screen.

The box can't reach my Emby server

  • Double-check the URL and Port fields — the URL should be the server's root address (e.g. https://192.168.1.10), not an API path.
  • Confirm the box and the Emby server are on the same reachable network, and that no firewall is blocking the configured port.
  • If the server is slow to respond (e.g. over Wi-Fi or a remote connection), raise Connection timeout and Connection read timeout under Timeouts.
  • Verify the User/Password are valid credentials on that Emby server — the plugin does not create accounts, only authenticates against existing ones.

I have more than one Emby server or user — do I need multiple installs?

No. Add one connection per server or per user in Setup, then toggle the checkbox on the connection you want active. See Managing connections.

Playback issues

Resuming a video starts at the wrong position, then jumps

This is usually a playback-engine settling delay. Try increasing Player initial seek delay (or the Exteplayer3-specific variant, if that's your active playback system) under Timeouts.

Switching audio tracks doesn't stick / reverts

Increase Audio track change settle delay under Timeouts — some playback engines need a little longer to report the newly active track.

Subtitles show garbled or wrong characters

This happens with legacy, non-UTF-8 subtitle files. Set Encoding for non-UTF-8 subtitles under Player Settings to match your content's language/encoding (Cyrillic, Japanese, Chinese, Arabic, etc.).

The Skip Intro button or Up Next screen never appears

  • Confirm the corresponding toggle (Show Skip Intro button / Show Up Next screen) is enabled under Player Settings.
  • Skip Intro only appears for items that have intro markers defined on the Emby server; Up Next only appears for episodes with a following episode available.

Which playback engine should I choose?

GStreamer/HiPlayer (whichever your box reports) is the default and works out of the box. Choose Exteplayer3 only if the ServiceApp plugin is installed and you specifically need its playback behavior (e.g. for certain stream formats).

Thumbnails & storage

Where are thumbnails cached, and can I clear them?

By default thumbnails go to a temporary location (/tmp) that's cleared on reboot. You can point Thumb cache location under UI Settings at a persistent HDD/USB mount instead — the plugin also performs automatic cleanup of stale entries.

Still stuck?

Open an issue on GitHub Issues with your Enigma2 image/version, the configured playback engine, and any relevant log output.
