Controls & Navigation

How the remote maps to actions across the home screen, library grids, detail screens, setup screens and the player.

General navigation

These mappings apply across the home screen, library grids and setup/connection screens.

OKExitBackRedGreenYellowBlueMenu
KeyAction
OKSelect the highlighted item / confirm.
Exit / BackClose the current screen and go back one level.
RedCancel / close without saving (setup and dialog screens).
GreenSave (setup and connection editor screens).
YellowContext action — e.g. add/edit a connection in Setup.
BlueContext action — e.g. remove a connection in Setup.
MenuOpen the context menu, where available.
Directional padMove the selection between items in a grid, list or the item action button row.

Item detail screens

Movie, series, season and episode detail screens show a row of contextual action buttons — the exact set depends on the item type and its state:

Play

Shown when the item has no playback progress yet.

Resume / Play from start

Shown together once playback progress exists, with the remaining time displayed on the Resume button.

Versions

Shown when an item has more than one media source, letting you pick which version to play.

Play trailer

Shown when the item has a linked remote trailer.

Watched

Toggles the played/unplayed state on the server.

Favorite

Toggles the favorite state on the server.

Go to series

Shown on episodes — jumps to the parent series' detail screen.

Move between buttons with left/right on the directional pad and press OK to activate the highlighted one.

Playback controls

The player is built on Enigma2's standard movie-player infobar, so the usual playback keys (play/pause, stop, fast-forward, rewind) work as on any other video. On top of that, E2EmbyClient adds:

KeyAction
Play / PauseToggle playback.
1 3 4 6 7 9Numeric quick-seek, same convention as the standard Enigma2 movie player.
UpShow the chapter/segment list.
DownShow the next-up playlist.
Info / EPGShow the info panel (title, plot, progress) over the video.
AudioOpen audio track selection — also lists available subtitle tracks, including embedded and external ones.
OKSelect the highlighted chapter or playlist entry.

Skip Intro

When an item has an intro marker and Show Skip Intro button is enabled (see Configuration), a Skip Intro button appears during the marked segment. Press OK while it's shown to jump past the intro.

Up Next

Near the end of an episode, if Show Up Next screen is enabled, an overlay appears showing the next episode with an autoplay countdown. Use left/right to move between its buttons (e.g. play now / cancel) and OK to confirm, or let the countdown finish to autoplay.

Subtitles & audio tracks

Open the audio selection dialog during playback to switch audio or subtitle tracks. Subtitle files using legacy, non-UTF-8 encodings (Cyrillic, Japanese, Chinese, Arabic, etc.) are decoded using the fallback encoding configured under Player Settings.
