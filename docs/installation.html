Installation

Three ways to get E2EmbyClient onto your Enigma2 box: a pre-built package, building it yourself, or wiring it into an image feed.

Before you start

  • An Enigma2 image running an FHD (1920×1080) skin. The plugin checks the desktop resolution on launch and refuses to start below that.
  • An Emby Server instance reachable from the box, and a user account on it.
  • Python 3 with the pillow and requests packages — these are declared as dependencies of the .ipk and installed automatically by opkg/apt.
  • Optional: the ServiceApp plugin, only needed if you plan to play back through Exteplayer3.

Option A — install a pre-built .ipk

This is the fastest route if you just want to run the plugin.

  1. Download the latest enigma2-plugin-extensions-e2embyclient_*_all.ipk from the project's GitHub releases page, or from your image feed if it's included there.
  2. Transfer the file to the box (network share, USB stick, or scp) and install it through your image's package manager — or from a terminal: 
    opkg install enigma2-plugin-extensions-e2embyclient_*_all.ipk
  3. Restart the GUI (or reboot the box) if prompted.
Tip

Most images also let you install .ipk files via the file manager (green/OK on the file) instead of the command line.

Option B — build the .ipk yourself

The build.sh script at the repository root packages the src/ directory into a Debian-style .ipk.

  1. Clone the repository: 
    git clone https://github.com/DimitarCC/e2-emby-client.git
cd e2-emby-client
  2. Run the build script: 
    ./build.sh
  3. Copy the resulting enigma2-plugin-extensions-e2embyclient_<version>_all.ipk from the repository root to your box and install it as in Option A.
Windows users

Run build.sh from Git Bash or MSYS2, not PowerShell or cmd.exe. You may need to install additional packages (for example ar.exe, part of binutils). Any POSIX shell works fine on Linux or macOS.

The script bumps the package version using the current git revision/commit hash, so every build is traceable back to a specific commit.

Option C — OpenEmbedded / image feed integration

If you maintain an Enigma2 image feed based on oe-alliance-core or openpli-oe-core, a BitBake recipe is provided at enigma2-plugin-extensions-e2embyclient.bb in the repository root. Add it to your feed's plugin layer the same way you would any other extension plugin recipe, then build and publish through your normal feed pipeline.

Next step

Once the plugin is installed, head to Setup & First Run to connect it to your Emby server.
