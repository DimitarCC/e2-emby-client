Setup & First Run

A walkthrough of connecting E2EmbyClient to your Emby server, from a fresh install to browsing your library.

1. Launch the plugin

Open Menu → Plugins → Extensions → Emby Player. If you enabled Add to Main Menu in the settings (see Configuration), you'll also find it directly on the main menu.

FHD skins only

If your current skin's resolution is below 1920×1080, the plugin shows an error message and exits immediately. Switch to an FHD skin first.

On the very first launch — before any server connection exists — the plugin skips the home screen and opens Setup automatically, since there's nothing to browse yet.

2. Add a server connection

  1. Open the connection editor

    In the Setup screen, scroll to the Connections section at the bottom and press OK or the Yellow button to add a new connection.

  2. Name the connection

    Give it a label of your choosing, e.g. Living Room Server or Home Emby. This is only used inside the plugin, purely for your own reference when you have more than one server.

  3. Enter the server address

    Fill in the URL field with the root address of your Emby server, for example https://192.168.1.10 or http://emby.local, and set the Port (the Emby default is 8096 for HTTP, commonly 8920 for HTTPS).

  4. Enter your credentials

    Fill in the Emby User and Password for the account you want the box to use. This should be an account that already exists on the Emby server — the plugin does not create new server accounts.

  5. Save

    Press Green (Save) to store the connection. It's added to the connections list and automatically marked as active if it's your first one.

3. Managing connections

You can configure more than one Emby server (or more than one user on the same server) and switch between them freely:

  • Press Yellow on an existing connection entry to edit it.
  • Press Blue on an existing connection entry to remove it.
  • Toggle a connection's checkbox to make it the active connection — this is the server the plugin talks to when you open the home screen.

4. Browse your library

Exit Setup once you have an active connection — the plugin loads the Emby home screen, showing your libraries (Movies, Series, and any other views configured on the server) as browsable rows and grids.

  • Open a library to see its grid view, with an alphabet/character bar on the side for quickly jumping to a letter.
  • Select any movie, series, season or episode to open its detail screen — cast, plot, ratings, genres and media info, alongside contextual action buttons (Play, Resume, Trailer, Watched, Favorite, etc.).
  • See Controls & Navigation for the full remote-control reference once you're browsing.
Multiple servers or users

Add a separate connection per server, or per user on the same server, then flip the active checkbox in Setup whenever you want to switch. There is no need to re-enter credentials each time — every configured connection is stored.
