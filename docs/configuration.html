Configuration Reference

All settings live under Emby Player → Setup, grouped into Timeouts, UI Settings, Player Settings and Connections.

Timeouts

SettingDefaultDescription
Connection retries count5 (range 5–20)Number of retry attempts for failed connections to the Emby server.
Connection timeout2 s (range 1–20)Timeout for establishing a connection to the server.
Connection read timeout10 s (range 2–20)Timeout for reading a response once connected.
Theme music settle delay300 ms (range 0–5000)Delay after theme music stops before the next stream starts playing.
Player initial seek delay10 ms (range 0–2000)Delay before the player's first seek attempt (GStreamer / HiPlayer).
Player initial seek delay (Exteplayer3)300 ms (range 0–2000)Same as above, tuned separately for Exteplayer3, which settles more slowly.
Audio track change settle delay500 ms (range 0–2000)Delay before re-checking the active audio track after switching, to let the playback engine settle.
When to touch the timeouts

Increase the connection timeout and retry count on flaky Wi-Fi links to a remote server. Increase the seek delays if you notice the player briefly showing the wrong position right after starting or resuming playback, particularly on Exteplayer3.

UI Settings

SettingDefaultDescription
Thumb cache locationTemporary (/tmp)Where poster/backdrop thumbnails are cached — a temporary location cleared on reboot, or a persistent mount point (HDD/USB) if one is available.
UI scroll delay150 msDelay between list selection-changed events, i.e. how fast you can scroll through a list before it fetches new info for the highlighted item.
Add to Main MenuOffExpose Emby Player directly on the Enigma2 main menu.
Add to Extensions MenuOffExpose Emby Player under Extensions, in addition to Plugins → Extensions.
Stop playing service on home loadOffStop the currently playing live service while browsing Emby, and restore it automatically when you exit the plugin.
Play theme musicOffPlay a movie's or series' theme music (if available on the server) while its detail screen is open. Only shown when Stop playing service on home load is enabled.

Player Settings

SettingDefaultDescription
Playback systemGStreamer / HiPlayerWhich playback engine to use: GStreamer or HiPlayer (whichever your box's media service reports), or Exteplayer3 if the ServiceApp plugin is installed.
Encoding for non-UTF-8 subtitlesLatinFallback character encoding applied to subtitle files that aren't UTF-8 — choose Latin, Cyrillic, Japanese, Chinese (Traditional or Simplified), or Arabic to match your content.
Show Skip Intro buttonOnShow a Skip Intro button during a marked intro segment.
Show Up Next screenOnShow the autoplay Up Next overlay with a countdown near the end of an episode.

Connections

The bottom of the Setup screen lists your configured Emby server connections. See Managing connections in the setup tutorial for how to add, edit, remove and switch the active one.

FieldDescription
NameA free-form label for the connection, shown in the connections list.
URLRoot address of the Emby server, e.g. https://192.168.1.10.
PortEmby server port. The Emby default is 8096.
UserEmby account username.
PasswordEmby account password.
